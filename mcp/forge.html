RHOBEAR MCP · Forge

Say it. Hold it.

Forge makes printable 3D models. Describe a thing or hand it a picture, say how tall it should be, and Forge returns a model you can print. Then fix it in plain words, or split a painted model into single-colour pieces and printer plates.

How it works

  1. Describe it or show it. “@forge, make a wall mount for this board, 12 cm tall.” Words, a picture, or both.
  2. Forge makes the model. The model comes back as a link, never as a file stuffed into the chat. One Forge job runs per account at a time.
  3. Fix it in words. “Make the base 2 mm thicker.” Forge returns a new model and keeps the one you started with. When it is painted, split it into single-colour pieces and printer plates.

The Forge tools

Your AI app sees each tool and its price before it runs. Every run draws from your RHOBEAR plan, and a run that never ran costs nothing.

  • forge.makeA printable 3D model from a description or a picture, at the height you ask for. Runs in the testing grounds
  • forge.editReshape or resize a model from a written instruction; returns a new STL.
  • forge.splitSplit a painted or textured model into single-colour pieces and printer plates.
  • asset3d.draftA quick 3D draft from one picture.
  • asset3d.generateA 3D model (GLB) from a picture.
  • asset.optimizeShrink a GLB to the phone and web budget.

In the testing grounds you can make a model from words or a picture. Reshaping and splitting run from your AI app.
